# Capas das categorias do blog

Coloque aqui uma imagem de capa para cada categoria. O nome do arquivo deve ser o **slug da categoria** + `.png`.

Exemplos (com base nas categorias atuais):

- `automacao-linkedin.png` → categoria "Automação Linkedin"
- `geracao-de-leads.png` → categoria "Geração de Leads"
- `prospecao-linkedin.png` → categoria "Prospecção LinkedIn"
- `sdr.png` → categoria "SDR"

**Formato:** `.png` (configurado no componente).

**Tamanho sugerido:** 640×400 px (proporção 16:10) para boa nitidez sem arquivos pesados.

Se não houver imagem para uma categoria, o card exibe um gradiente suave no lugar da capa.
